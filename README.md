# claude-mods

Claude Code mods.

## auto-session-title

- Renames a session to a short fitting title after its 3rd prompt, then refreshes it every 10 prompts.
- `/done` puts ✅ in front of the title, `/undone` takes it off.

Install: `/plugin marketplace add <path-or-owner/repo>` then `/plugin install auto-session-title@claude-mods`.
